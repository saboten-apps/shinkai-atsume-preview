# 地面・道路の航空写真表示

2026-11-14追加。本体`src/features/exploration/map/three/aerialGround.ts`が実装。previewへは通常の同期スクリプトで反映する。

## データと出典

国土地理院の「全国最新写真（シームレス）」を利用する。URLは公開XYZタイル：

`https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg`

- タイル一覧・利用条件：https://maps.gsi.go.jp/development/ichiran.html
- 国土地理院コンテンツ利用規約：https://www.gsi.go.jp/GSI/chosaku.htm
- 写真の説明：https://maps.gsi.go.jp/legend/seamlessphoto.pdf

一覧の「基本測量成果以外で出典の記載のみで利用可能なもの」に含まれる写真レイヤを使用する。表示と書き出しには「地理院タイル（国土地理院・全国最新写真）を加工」と出典を追加した。PLATEAU出典も保持。撮影年は場所ごとに異なり、建物モデルの2021年度と一致する保証はない。実測図や現地案内としての精度は保証しない。

## 表示方式

- 元の地形DEMを保ち、WGS84 ECEF→ENUと逆の変換で各頂点の緯度経度を求め、XYZ写真と位置を合わせる。原点は北緯35.0815、東経138.8576、楕円体高0。x=東、y=上、z=-北。
- 全体用z15を12枚（現在のDEM範囲）、近傍詳細用z18を最大32枚。同時リクエストは最大3件。各写真は256×256px。ガチャ・2D探索でタイルは取得しない。
- 地形頂点とUVを共有し、写真タイルごとの三角形インデックスだけを分割する。頂点の重複コピーや全面8K写真は使わない。
- 遠い詳細写真は移動時に解放する。形状のインデックスはDEMの有限範囲で再利用し、探索終了で破棄する。
- 元の海・川の面を1024×2048のマスクにし、写真と地形を水面へ重ねない。マスクは描画用で、衝突形状は変えない。
- 道路の単色面を薄い舗装色にし、航空写真の車線・横断歩道・駐車区画などが見えるようにした。存在しない白線や歩道を生成していない。
- 写真の取得に失敗した場合は元の地形色で表示を継続する。写真は次回要求まで60秒の再試行間隔を設ける。通信待ちは飛行を止めない。

## 確認

- 緯度経度変換の3テストを追加（合計28件）。独立したWGS84前方計算の駅位置を逆変換して一致を確認。
- `scripts/check-ground-photos.mjs`で、港と駅で概観12枚・詳細32枚以内、256px画像、港の詳細32枚の解放、CORS対応PNG書き出しを確認。写真通信を止めても地形が残ることを確認。WebGLシェーダーエラーなし。
- 実際の航空写真を使った10か所のカード背景を再生成。`public/map/cards/validation.json`に写真メッシュ数も記録。
- `scripts/check-exploration-3d.mjs`で通常の飛行・探索・発見・共有用カードの一連の操作を確認する。

ネットワークにプロキシが必要な開発環境では、ブラウザ検証・カード背景生成に`BROWSER_PROXY`を指定できる。ユーザーのアプリにはプロキシ設定や秘密情報を埋め込まない。

```sh
npm run dev -- --port 5180
node scripts/check-ground-photos.mjs
node scripts/generate-discovery-scenes.mjs
```

## 実機で確認すること

Pixel 10 Proで、航空写真が表示された後のFPS、連続飛行、発熱、港⇄駅の移動、低速回線、カード保存を確認する。以前の「60FPS」の画面は航空写真追加前のため、追加後の性能は別に測る。重い場合は詳細枚数を24へ、詳細ズームを17へ落とす調整が可能。
