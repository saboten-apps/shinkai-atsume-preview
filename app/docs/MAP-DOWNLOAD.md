# LOD3と端末保存

2021年度 bldg_lod3 に建物28区画を置換。LOD2の配信ファイル・比較ページ・LOD2用追加画像は削除。
LOD3の収録は7,061棟（旧LOD2は7,327棟）。収録差があり、旧建物の完全な一対一置換ではない。
元写真の大きなアトラスのみ2048pxに縮小、ジオメトリはMeshopt圧縮。モデルがLOD3でも全ての建物に窓の立体形状があるとは限らない。
建物配信48,371,184バイト、地形・道路・水面・環境写真を含む保存対象はビルド時に実測。
区画読み込み350m、解放650mでGPUメモリを制限。

ガチャ結果の「街データを事前保存」、探索の「案内・設定」から保存可能。
Cache Storage + Service Workerで同一バージョンのファイルを再利用。保存前にSHA-256とバイト数を照合。
中断・失敗時は保存済みファイルを保持して再開できる。全件完了後に旧バージョンの専用キャッシュを削除。
図鑑・ガチャ・発見のlocalStorageには触れない。画像タイル・アプリ本体の完全オフライン起動は対象外。
ブラウザ容量不足・自動削除で再取得が必要になる場合がある。

ビルド前に公開用map/dataを準備すること。previewはprepare-app-map.mjsで正しいmanifestと区画をコピーし、古いファイルを除去。
`build-map-download.mjs` が配信中のファイルからmanifestとService Workerのバージョンを生成する。
