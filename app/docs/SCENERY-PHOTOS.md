# 自由な景色撮影と共有URL（2026-11-16）

## 体験

- 今日の画面に「沼津の景色を眺める・写真を撮る」の入口を追加。ガチャを主役のままにする。
- `#/view`、`#/view/port`、`#/view/byuuo`、`#/view/city-hall` は軽い案内画面。
- 「3Dで景色を見る」を押すまでThree.js、GLB、建物選択データを読み込まない。
- 3Dの好きな位置から「景色を撮る」。探索中・発見後の散策中・ガチャ未実施の景色閲覧で利用できる。
- 操作UI、キャラクター、魚、選択ハイライト、ピンを除いた景色を撮影する。撮影後のプレビュー中は移動を停止。
- 縦・横の構図を維持したPNGに枠、うみまちラボ、バーチャル景色の説明、PLATEAU/GSIの出典を付ける。
- 画像保存、Web Share対応端末での共有、景色URLのコピー、手動コピー用テキストを提供する。
- 「街に戻る」で同じ探索を続けられる。画像は一時メモリだけで保持し、閉じる／離脱時にObject URLを解放する。

## 共有リンク

形式: `#/view/v1?c=x,y,z&t=x,y,z&p=x,z&f=fov`

cはカメラ、tは注視点、pは街データの読み込み中心、fは垂直視野角。既存のENU座標系を使う。数値は小数点以下2桁で保存。
名前やHTML、外部URL、魚ID、日付、図鑑データ、端末のGPSは含めない。
リンク長、引数の個数・重複、有限数値、範囲、視野角、カメラと注視点の距離を検証する。
不正・未知版・途切れたリンクはエラー案内にして、3Dを読み込まない。
共有リンクで魚の取得・発見は発生しない。既存 `#/explore/日付` のガチャ履歴チェックは変更しない。

同じ位置・向き・垂直視野角を再現するが、画面の縦横比、水面の動き、データの更新で画像は変わる。
**画像そのものをURLに保存する機能ではない。SNSの投稿には保存画像を添付する。**
GitHub Pagesの静的配信とハッシュルートなので、景色ごとのSNSプレビュー画像・OGP生成は対象外。

## 軽量表示・障害時

案内画面の「2Dで場所を見る」は共有視点の周辺を模式図で示す。実際の道案内ではない。
WebGL不可、3Dチャンク読込失敗、描画中断時は案内と2D位置図へ戻す。
ガチャ不要の景色閲覧から魚を取得する導線や、発見処理への直接アクセスは作らない。
DB、アカウント、投稿受付、画像アップロード、共有回数の集計、外部メッセージ送信は追加していない。

## 実装

- `src/features/scenery/viewpoint.ts`: 数値だけのURL仕様、検証、3つの案内地点。Three.js非依存。
- `SceneryPage.tsx`: 軽い案内、2D位置図、明示操作後の3D遅延読み込み。
- `photoCard.ts`: 構図を保つPNG生成。元画像の最長辺を最大1600pxにし、クレジット欄を追加。
- `PhotoPreview.tsx`: プレビュー、保存・共有、フォーカス移動／キーボード操作。
- `Map3DView.tsx`: 現在視点の撮影、対象物の一時非表示・復元、視点復元、プレビュー中の停止。
- `portFlight.ts`: キャラクターを非表示で撮影し、例外時も元の可視状態へ戻す。
- `App.tsx`: sceneryルートを遅延読み込み。探索の魚取得条件は維持。
