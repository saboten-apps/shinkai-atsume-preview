# 場所の紹介カード（2026-11-16）

建物の長押し後に、場所の名前・提供済み写真・短い構造紹介・共有ボタンを表示する。
市役所（庁舎と入口の原本ID）とびゅうおを `src/features/scenery/places.ts` で紐づけた。
近隣建物を誤って紹介しないよう、座標範囲や `isCityHall` だけでは判定しない。
写真は選択後に取得し、失敗時も紹介・共有を利用できる。
カードは画面高の58%まで、建物ID・座標・修正台帳は折りたたみで確認できる。
未登録は「この建物の紹介はまだありません」と表示。

共有は既存の `#/view/city-hall` / `#/view/byuuo` を利用する。
Web Share APIがなければリンクコピー、失敗時は表示したリンクから共有可能。
3Dを開く前の案内・2D代替も既存の景色ページを利用する。
紹介は施設との提携や営業状況を示さず、来訪記録も作らない。
追加登録は写真の利用条件、原本ID、日英紹介、既存の視点リンクを確認して行う。

検証: Vitest（登録先の写真・URL・ID、隣接建物の非該当）、ビルド。
ブラウザ検証: `scripts/check-place-introductions.mjs`（Playwright / Chromium）。
Pixel 10 Proでの操作・共有シート・体感性能は実機確認が必要。
