# 深海あつめ 3Dスパイク：実データ統合・第4弾 指示書

設計根拠: ../DESIGN-astra-round3.md の D3/T2（実テクスチャの後付け適用）。**本アプリ（../app）は変更禁止。**

## データ差し替え（../realdata-test/ から public/data/ へ）
- 建物カラー版: `port-bldg-color-packed.glb` を廃し、**`port-bldg-color-nohero-packed.glb`**（目印建物49棟を除いた476棟、370KB）に差し替える。初期表示はこれを使う（第3弾より軽い）。
- 目印建物テクスチャ版: **`port-bldg-hero-tex-packed.glb`**（49棟・実写真テクスチャ内蔵、1.27MB）を追加する。

## 変更内容
1. 初期ロードではカラー版（nohero）＋地形・植生・道路・水面を従来どおり表示する。
2. ヒーローテクスチャ版は、初期表示の完了後に遅延ロードする（初回レンダリング後、requestIdleCallback または数百msのタイマーでよい）。ロードできたらシーンに追加する。失敗してもカラー表示のまま壊れないこと（ヒーロー49棟はカラー版から抜けているので、失敗時はその49棟が欠ける。許容するが、コンソールエラーで落とさない）。
3. ヒーロー版のマテリアルはGLB内蔵のテクスチャと色をそのまま使う（頂点カラーの生成りティントを掛けない。テクスチャ面にはCOLOR_0が無く、無テクスチャ面のCOLOR_0は源データの中立グレー）。
4. 描画コールは合計40以内を目標とする（第3弾は21）。ヒーロー版の追加で大きく増える場合は、テクスチャ単位のメッシュ統合など無理のない範囲で抑える。
5. その他（ピン・パネル・HUD・水面・2D代替・出典フッター・CSSの `#root { height: 100% }`）は第3弾のまま維持する。
