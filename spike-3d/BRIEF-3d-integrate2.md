# 深海あつめ 3Dスパイク：実データ統合・第2弾 指示書

## 前提
第1弾（BRIEF-3d-integrate.md）で建物LOD2・道路LOD3の実データ化が完了した状態から続ける。**本アプリ（../app）は変更禁止。**

## 追加データ（../realdata-test/ から public/data/ へコピー）
- `port-terrain-packed.glb` — 地形（海岸線と起伏を含む）
- `port-veg-packed.glb` — 植生（千本松原の松など）
座標系・地面の高さ（y≈41.7）は第1弾と同じ。

## 変更内容
1. **地形の投入**: 第1弾の「陸の土台平面（2400×2400、y=41.45）」を地形GLBに置き換える。地形マテリアルは生成りサンドを少し深くした色（0xcfc5ae）、roughness 1.0。
2. **周囲の敷き分け**（地形の範囲外の見え方）:
   - 海: 濃紺平面（2400×2400）を y=41.5 に敷く（全面）。理由: 地形データの沖合部分は補間値で y≈41.4 にあり、海面を41.5にすると沖合地形が沈み、標高41.7以上の陸だけが浮かぶ。港の岸壁（41.7〜42.3）は水没しない。
   - 南と東の地続き表現: 生成り色の平面を y=41.55 に、z > +720 の南側一帯と x > +590 の東側一帯だけに敷く（地形範囲の外側）。北と西は海のままにする。
3. **道路の浮き上がり修正**: 道路メッシュの表示位置を y +0.4 ずらし、土台との z-fight と「線が途切れる」問題を解消する。あわせて道路マテリアルに polygonOffset（factor: -1, units: -1）を付ける。
4. **植生の投入**: veg GLBを読み込み、深緑（0x243e2b）のフラットカラー、roughness 1.0 で表示する。
5. **初期カメラの詰め**: 港と海が両方入る構図にする。初期位置およそ (330, 300, 470)、注視点 (-30, 43, -140)。controls の制限は第1弾のまま。
6. 建物・ピン・HUD・2D代替・出典フッターは第1弾のまま維持。CSSの `#root { height: 100% }` は絶対に崩さない。
