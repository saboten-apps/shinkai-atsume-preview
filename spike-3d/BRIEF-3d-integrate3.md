# 深海あつめ 3Dスパイク：実データ統合・第3弾 指示書

設計根拠: ../DESIGN-astra-round3.md（GPT Astra設計）。今回は設計の段階1（カラー版＋水域分離の完成）を行う。実テクスチャの後付け適用（設計のD3/T2）は今回の対象外。**本アプリ（../app）は変更禁止。**

## データ差し替え・追加（../realdata-test/ から public/data/ へコピー）
- 建物: `port-bldg-lod2-clean-packed.glb` を廃し、**`port-bldg-color-packed.glb`** に差し替える（屋根/外壁を面法線で塗り分けた頂点カラー版。元データに用途属性が存在しないため全棟「不明」パレット：壁 #CFCEC8／屋根 #777C7C、建物ごとの明度差つき）。マテリアルは従来どおり vertexColors: true。
- 水面: **`port-water-sea-packed.glb`** と **`port-water-river-packed.glb`** を追加する（土地利用データの水面ポリゴン、頂点カラー焼き込み済み、海 #183B52／川 #527B78系）。どちらも y=0 相対の平面メッシュなので、配置時に海は y=41.55、川は y=41.62 へオフセットする。

## 変更内容
1. 海の全面平面（従来の濃紺プレーン）は色を #183B52 に合わせて残す（y=41.5）。その上に水面ポリゴン（海）を重ね、内港・河口・港沖の水際をデータどおりに読めるようにする。
2. 川ポリゴンは海より少し高い y=41.62 に置き、狩野川の流路が色（#527B78、明るい灰緑）で判別できるようにする。
3. 水面の質感: 128×128程度の小さなノイズテクスチャを自前生成し、roughnessMap として水面マテリアル（海・川）に適用する。レンダーループで offset を、海は極低速、川は下流方向（北＝−z側へ流れる向き）へ低速でスクロールさせる。模様は低コントラストに抑え、静止画でも色で判別できることを優先する（アニメーションは補助）。
4. 建物・地形・植生・道路・ピン・情報パネル・HUD・2D代替・出典フッターは第2弾のまま維持する。CSSの `#root { height: 100% }` は絶対に崩さない。
5. 容量ガードレール（設計値）: 3Dアセット合計 1.5MB 以内、表示 tris 180k 以内、描画コール 40 以内を守る。現在の構成では合計 約1.06MB になる想定。
