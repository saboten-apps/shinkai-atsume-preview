# 深海あつめ 3Dスパイク：実データ統合 指示書

## 目的
技術検証スパイク（このフォルダ）の手続き生成ジオメトリを、PLATEAU実データ（沼津港周辺）に差し替える。検証の主眼は「実データでもスマホで触れるか」のまま。**本アプリ（../app）は変更禁止。**

## 使うデータ（../realdata-test/ から public/data/ へコピーして使う）
- `port-bldg-lod2-clean-packed.glb` — 建物LOD2（屋根形状あり、建物ごとに頂点カラーの濃淡つき）。※必ずこの "clean" 版を使うこと（初期版GLBは軸変換ミスがあり使用禁止。詳細は ../realdata-test/RESULT.md §8）
- `port-road-packed.glb` — 道路LOD3（駅〜港コリドー分のみ）
- 地形データは配布ZIP内に存在しないため使わない。
座標系はすべて共通のローカルENU（原点=沼津港 緯度35.0815/経度138.8576、x=東、y=上、z=−北、単位m）。**重要な注意: この座標系では地面の高さは y≈41.7（楕円体高ベース）で、建物の基礎は y≈40.7〜41.9 にある。** 土台は次のように敷く:
- 陸の土台: 生成り色の平面（2400×2400）を y=41.45 に敷く（建物基礎の少し下）
- 海: 濃紺の平面（2400×2400）を y=41.15 に敷く（陸より少し低く）

## 統合内容
1. `src/three/sceneBuilder.ts` の手続き生成（市街ブロック・陸地・びゅうお等の模型群）は撤去し、GLTFLoader＋MeshoptDecoderで上記GLBを読み込む構成にする。読み込み完了までは「読み込み中」の小さな表示を出す。
2. マテリアル（標本図鑑トーン厳守）:
   - 建物: MeshStandardMaterial、vertexColors: true（GLBの頂点カラーを使用）、roughness 0.85
   - 道路: 濃いスレート色（0x3d4b53系）、roughness 0.9
   - 陸の土台: 生成りサンド（0xd7cfbe）、roughness 1.0
   - 海: 従来の濃紺、y=41.15、範囲 2400×2400
3. カメラ・操作（対象範囲は約850m四方に拡大）:
   - 初期位置およそ (390, 350, 430)、注視点 (0, 43, -80)（港側＝北寄り、yは地面41.7付近）
   - controls: minDistance 40、maxDistance 1400、maxPolarAngle は従来どおり
   - FogExp2 の濃度は 0.0008 程度に下げる
4. 仮ピン5件を実座標へ移す（x,zは上記ENU。ピンの柱・マーカーは地面 y≈41.7 を基準に立てること。従来方式の絶対y前提は地面41.7に合わせて読み替える）:
   - びゅうお周辺（仮）: (-210, -366)
   - 深海水族館周辺（仮）: (-73, -300)
   - 魚市場周辺（仮）: (-36, -233)
   - 千本松原（仮）: (355, 78)
   - 狩野川河口（仮）: (219, -411)
   ピンの文言・「仮ピン」明記・情報パネル・スタンプ体験は現行のまま流用。
5. HUD（FPS/Calls/Tris表示）、2D代替表示、WebGLフォールバック、ヘッダー/フッター（出典表記含む）は現行のまま維持する。
6. CSSの `#root { height: 100% }` 修正は絶対に崩さないこと（過去に高さ0潰れで真っ暗になった事故あり）。
