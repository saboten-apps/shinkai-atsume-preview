# PLATEAU 3D都市モデル（沼津市）調査レポート

- 調査日: 2026-11-12
- 目的: 「深海あつめ」の軽量3Dマップ（沼津港周辺）のデータ候補として、国土交通省 Project PLATEAU の沼津市3D都市モデルの有無・範囲・LOD・利用条件を確認する
- 凡例: 各主張に出典URLを付記。確認できなかった項目は **未確認** と明記する

## 1. データセットの存在・整備年度・最新版

- 沼津市は2020年度（令和2年度）開始時の全国56都市の一つとして3D都市モデルが整備・オープン化された。沼津市公式ページが明記している。
  - 出典: 沼津市「Project PLATEAU 3D都市モデル」 https://www.city.numazu.shizuoka.jp/shisei/office/ichiran/toshikei/machiseisaku/plateau/
- G空間情報センターに以下の2データセットが公開されている。
  - 2020年度版: https://www.geospatial.jp/ckan/dataset/plateau-22203-numazu-shi-2020
  - 2021年度版: https://www.geospatial.jp/ckan/dataset/plateau-22203-numazu-shi-2021
- 2021年度版は沼津市をフィールドとした **LOD3データ作成実証**（建築物・道路・都市設備・植生）を含む更新版である。
  - 出典: 国土交通省「3D都市モデルの導入ガイダンス」等 https://www.mlit.go.jp/plateau/file/libraries/doc/plateau_doc_00001_ver05.pdf
- バージョン: 2021年度版データセット内では「最新版データはV2」（標準製品仕様書V2対応。2023年4月6日にV2対応データを追加、同年5月12日にユースケースデータを追加）。データセット自体のバージョン表記は 1.0.0、最終更新 2024-10-05。
  - 出典: https://www.geospatial.jp/ckan/dataset/plateau-22203-numazu-shi-2021
- 国土交通省のチュートリアルも「沼津市の3D都市モデルには2020年度版と2021年度版があり、第1.0版と第2.0版のCityGMLが提供されている」と説明している。
  - 出典: https://www.mlit.go.jp/plateau/learning/tpc21-1/
- **未確認**: 2022年度以降の新規・更新データセット（本調査の検索範囲では存在を確認できず。PLATEAU Open Data一覧（2026-05-11更新）にも沼津市は掲載されているが、リンク先は上記データセット群） https://www.mlit.go.jp/plateau/open-data/

## 2. 地理的カバー範囲（沼津港を含むか）

### LOD別の作成範囲（2021年度版データセットの「仕様」欄）

| LOD | 作成範囲 |
|---|---|
| LOD1 | 187.10 km² |
| LOD2 | 4.23 km² |
| LOD3 | 2.36 km² |

- 出典: https://www.geospatial.jp/ckan/dataset/plateau-22203-numazu-shi-2021 （2020年度版もLOD1 187.10 km² / LOD2 4.23 km²と同値）

### 沼津港周辺の扱い

- **LOD1（187.10 km²）**: 沼津市の面積は186.84〜186.96 km²（国土地理院「全国都道府県市町村別面積」ベース。市統計では平成17〜22年時点の面積表記が187.10 km²）。LOD1作成範囲は当時の市域面積と一致し、**市域全域カバーと判断できる。したがって沼津港・千本港町周辺もLOD1（箱型建物＋高さ）では収録されている**。
  - 出典: 沼津市統計資料（面積187.10 km²の時期表記あり） https://city.numazu.shizuoka.jp/shisei///profile/tokei/r07data/i2/it2-all.pdf ／ 市プロフィール（現行面積186.84 km²） https://city.numazu.shizuoka.jp/shisei/profile/whats/profile.htm
- **LOD3（2.36 km²）**: 日本測量協会誌の表紙解説（国際航業による整備解説）によれば、LOD3整備の対象は **「静岡県沼津市の沼津駅から沼津港までのルート周辺」** で、建物の詳細形状・テクスチャに加え、看板・アーケード・交通標識・道路標示・街灯等の都市設備、植生まで整備された。
  - 出典: https://sokugikyo.or.jp/wp-content/uploads/2024/04/117_coverre.pdf （二次資料。一次資料として国交省ガイダンスも沼津市でのLOD3実証＝建築物・道路・都市設備・植生を裏付け）
- **LOD3対象メッシュ**: 国土交通省 PLATEAU Technical Report（UC23-18 VPS技術検証）には、2021年度版CityGML（`22203_numazu-shi_2021_citygml_4_op.zip`）の対象第3次メッシュとして `5238-5628, 5238-5629, 5238-5618, 5238-5619, 5238-5608, 5238-5609, 5238-4698, 5238-4699` が列挙されている。これらを緯度経度帯に読み替えると、経度138°51′〜138°52′30″、緯度35°04′30″〜35°06′30″の南北コリドーとなり、沼津駅付近から狩野川河口・沼津港方面へ下る帯と符合する（メッシュコード換算による目安）。
  - 出典: https://www.mlit.go.jp/plateau/file/libraries/doc/plateau_tech_doc_0088_ver01.pdf
- **LOD2（4.23 km²）の正確な範囲図**: **未確認**（データ目録XLSX・範囲図を確認できていない。技術検証レポートでは駅〜港コリドーのメッシュで建築物LOD2がLOD3のない部分の補完に使われており、同コリドーを含むことは確認できる）。
- **個別施設単位の収録保証**: **未確認**（例: びゅうお、水族館等の個別建物がどのLODで入っているかは、実データの目録照合が必要）。

## 4. ダウンロード形式・入手経路・ファイルサイズ

- 入手経路: **G空間情報センター（一般社団法人社会基盤情報流通推進協議会が運用）のPLATEAUポータル**から無料ダウンロード（沼津市ページ・国交省ページ双方が案内）。
  - ポータル: https://www.geospatial.jp/ckan/dataset/plateau
  - 沼津市2021年度版: https://www.geospatial.jp/ckan/dataset/plateau-22203-numazu-shi-2021
- 提供単位: 建築物は第3次地域メッシュ（約1 km四方）、建築物以外は第2次地域メッシュ（約10 km四方）。
- 2021年度版の提供形式: **CityGML 2.0 / 3D Tiles / MVT / 2D Shape / GeoJSON**
  - CityGML（v1・v2の2系統）、3D Tiles・MVT（v2）等がZIPで提供される。
- 2020年度版の提供形式: CityGML 2.0 / 3D Tiles / GeoJSON / MVT / Shape / **ファイルジオデータベース（FGDB）** / **GeoTIFF（オルソ写真、解像度40cm、撮影2017年）**
- **FBX / OBJ**: 沼津市の提供形式には **含まれていない**（ポータル記載ベース）。FBX等への変換データが公式提供されるのは東京23区など一部のエリアのみで、沼津ではCityGML→変換は利用者側で行う必要がある。
  - 出典（一般論）: 総務省資料 https://www.soumu.go.jp/main_content/000839747.pdf ／ OSM Wiki https://wiki.openstreetmap.org/wiki/MLIT_PLATEAU
- ファイルサイズ:
  - 確認できたもの: 2020年度版FGDB 約564 MB（解凍後 約9.7 GB）— ポータル明記。
  - **未確認**: CityGML（v2）ZIP、3D Tiles ZIPのサイズ。ポータルの取得テキストにサイズ表記がなく、CKAN API経由のメタデータ取得もアクセス拒否（403）で確認できなかった。取得時に実測が必要（市全域分はGB級になる想定だが、これは未確認の推測として扱うこと）。

## 5. ライセンス・利用条件

### 適用条件

- G空間情報センターの沼津市データセットの「使用許諾」欄: 「Project PLATEAUのサイトポリシーに従って、どなたでも、複製、公衆送信、翻訳・変形等の翻案等、自由に利用できます。**商用利用も可能です**。」
  - 出典: https://www.geospatial.jp/ckan/dataset/plateau-22203-numazu-shi-2021
- PLATEAUサイトポリシー（コンテンツの利用）:
  - G空間情報センターで公開している3D都市モデルを含むコンテンツは、特記がない限り **「公共データ利用規約（第1.0版）」（PDL1.0）に準拠した利用条件** で利用できる。
  - 著作権: PLATEAUウェブサイトのコンテンツは原則国土交通省に帰属するが、**3D都市モデルのオープンデータの著作権は各地方公共団体（＝沼津市）に帰属** すると明記されている。
  - 本ルールは **CC BY 4.0（表示4.0国際）と互換性** があり、国土交通省は利用者がCC BYに従って利用することを許諾。希望する場合は **ODC BY / ODbL** での利用も妨げない（マルチライセンス的運用）。
  - 出典: https://www.mlit.go.jp/plateau/site-policy/

### 出典記載（必須）

サイトポリシーの「PDL1.0に関する重要事項」より:

1. コンテンツを利用する際は **出典を記載** すること。記載例:
   - `出典：国土交通省 PLATEAUウェブサイト（当該ページのURL）`
   - データ利用の実務では、データセット名・提供主体・URLを含める形が安全（例: 「3D都市モデル（Project PLATEAU）沼津市（2021年度）（国土交通省・沼津市、G空間情報センター）を加工して作成」— 下記2と合わせた形）。
2. **編集・加工等して利用する場合は、出典とは別に、編集・加工等を行ったことを記載** すること。記載例:
   - `「○○」（国土交通省）（URL）を加工して作成`
   - `「○○」（国土交通省）（URL）をもとに○○作成`
3. 編集・加工した情報を、**あたかも国土交通省が作成したかのような態様で公表・利用してはいけない**。

### 商用利用・加工再配布（Webゲームのマップ用途）

- **商用利用: 可**（データセット使用許諾・PDL1.0の双方で明示）。
- **加工・翻案: 可**。「翻訳・変形等の翻案等、自由に利用できます」と明記されており、**ジオメトリを簡略化（ローポリ化）してWebゲーム用マップとして再配布・配信する形態も、この文言の範囲内** と読み取れる。その際の義務は (a) 出典記載、(b) 加工した旨の別記、(c) 国交省作成と誤認させる表示の禁止、の3点。
- 注意点（サイトポリシー明記）: 一部コンテンツには個別法令による制約があり得るものとして **測量法に基づく公共測量の測量成果の利用** が挙げられている。3D都市モデル自体は上記の通りオープン利用が前提だが、測量成果そのものの転用など特殊な使い方をする場合は要確認。
- **未確認**: 沼津市独自のオープンデータ利用規約がPLATEAUデータにも重ねて適用されるか（市オープンデータページは市の規約への従属を案内するが、PLATEAUデータについては市ページ自体がG空間情報センター／PLATEAUサイトポリシーへ誘導している。本データセットの使用許諾欄はPLATEAUサイトポリシーを指定）。
  - 出典: https://city.numazu.shizuoka.jp/shisei/office/ichiran/seisaku/ictsuishin/opendata.htm

## 6. 「深海あつめ」3Dマップへの含意（調査者メモ）

- 沼津港周辺は、LOD1全域カバーに加え、**駅〜港コリドーがLOD3（テクスチャ付き建物・道路・都市設備・植生）の実証エリア** という、全国的にも恵まれた条件。軽量3Dマップの出発点としてデータ面の裏付けは強い。
- 実務ルート: CityGML（v2）から港周辺メッシュ分だけを抽出 → 簡略化（LOD1形状ベース＋主要ランドマークのみLOD2/3形状）→ Three.js用に変換、が現実的。3D Tiles版も提供されているため、タイル配信の検討も可能。
- 表記義務の実装: アプリ内About／クレジットに「出典: 3D都市モデル（Project PLATEAU）沼津市（国土交通省・沼津市）」＋「本マップは同データを加工（簡略化）して作成」の2点を常設する。
- データの鮮度: 基礎は2020/2021年度整備（測量・撮影時期はそれ以前のものを含む）。港周辺の新しい施設が欠けている可能性があり、実データでの目視確認が前提。

## 7. 未確認事項一覧

1. LOD2作成範囲（4.23 km²）の正確な範囲図・対象地区名
2. 橋梁・トンネルモデルの有無（ポータル抜粋では未掲載）
3. CityGML（v2）ZIP / 3D Tiles ZIPのファイルサイズ（CKAN APIが403で取得不可だった）
4. 港周辺の個別ランドマーク建物（びゅうお等）が収録されるLODの確定（実データ目録の照合が必要）
5. 2022年度以降の沼津市データセットの有無（検索範囲では見つからず）
6. 沼津市オープンデータ利用規約のPLATEAUデータへの重畳適用の有無
